# Words the hub uses

| Word | Means |
|---|---|
| Provisional | A date the hub proposed; nobody has confirmed it. Drawn faded and dashed. |
| Confirmed | A date someone set on purpose, or that matches Buildertrend. |
| Pinned | A promised date. Nothing moves it. |
| Overdue | The date has passed and nobody ticked the step. |
| Needs a decision | The dates break a rule and someone has to say what to do. |
| Done | Ticked, by whoever did it. |
| Step | One thing on a job with a date: check measure, production drawings, cut, install. |
| Task | Extra work for one job only, or a piece of rework. |
| Rework | Work done again because something went wrong, with its own tasks and hours. |
| Flag | A problem for someone to deal with. |
| Area | A Board row a person works in. Their steps make up My day. |
| Spoken for | Stock allocated to a job and not yet picked. |
| Free | On hand less spoken for. |
| Standing line | Stock always kept, with a minimum. |
| Shortfall | What a job needs that isn't on hand or on order. |
| Suggestion | Something the Buildertrend bot found that doesn't match. |
| Site link | An installer's way into one job. |
| Signed off | The site manager's Install done tick. The installer's "finished from our side" isn't. |

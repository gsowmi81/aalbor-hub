# Stock: Bins

Every standing line can have a bin with a QR label (More → Stock → Items → **Bin labels ↗**, printed on A4). Scanning a label on a phone opens that bin's page with one button, **Running low**, which puts the item's reorder quantity on the order list. A second scan says it's already listed.

Minimums, reorder quantities and bins are set on each item. Notion had none, so they are empty until someone sets them; Running low only checks standing lines with a minimum.

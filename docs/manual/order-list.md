# Stock: Order list

More → Stock → Order list. Open lines grouped by supplier, each saying what it's for (a job, running low, a gap).

- **Ordered**: when the order is placed, with the expected date. The line goes amber and the jobs waiting on it show "on order".
- **In**: when it arrives, with the quantity. A partial stays on order for the rest. Stock received for a job marks that job's line as on hand.
- **Drop**: a line that shouldn't be ordered.
- **Add a line** for anything else.
- **Received and dropped** folds away at the bottom.

Christine runs the list. The factory can mark lines **In** as deliveries arrive.

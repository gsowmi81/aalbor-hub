# The weekly stock cycle

- **Daily**: deliveries are marked **In** on the order list as they land (quantity; a partial stays on order). The factory **picks** as jobs start, logs offcuts, scans a bin when it's running low.
- **Friday**: the factory counts the standing lines (Stock → Count). Each difference is logged.
- **Monday**: Christine opens **Need and supply**: the gaps for the next six weeks and by when to order each, then **Order list** grouped by supplier, places the orders and marks them **Ordered** with the expected dates.
- **As jobs get production plans**: their cut lists are loaded and sourced, so the six-week view is real.

Minimums, reorder quantities, lead days and bins live on each item and were empty at the start; set them as you go.

# Rework, start to finish

1. **Raise it.** More → Rework, or **Raise rework** on the job, or **Raise rework for this** on a flag. The job, the cause, one line on what happened, and tick what needs doing: drawings, factory work (hours), delivery, install (hours). Anyone who can tick can raise it.
2. **Date it.** Editors: a start date on the raise form, or **Set dates** on the rework, fills the dates in order (drawings, then factory work for the hours, then delivery, then install) and confirms them. Each task is a red card in its area's row on the Board and on My day for whoever does it; the factory hours count against capacity.
3. **Do it.** Tick each task done as it's finished, like any step.
4. **Close it.** **Close this rework** with the rough extra hours and material cost. Owners record who was responsible.

Moving one task moves the later ones of the same rework by the same working days; the main job never moves because of rework. The monthly tally on the Rework page is by cause.

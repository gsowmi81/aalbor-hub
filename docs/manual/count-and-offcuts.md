# Stock: Count and Offcuts

## Count

More → Stock → Count. The standing lines (or **Everything** for a stocktake), grouped by category, with the bin, the last count and what the hub says is there. Type what's on the shelf; leave a box empty to skip it. **Save the count**. Each difference becomes a count move with your name, and the item page shows it in the ledger. Lines marked **check** were doubtful in Notion and haven't been counted since.

The factory counts on Fridays.

## Offcuts

More → Stock → Offcuts. Pieces over half a sheet of colours we don't keep. **Log an offcut**: the colour, length and width, where it is. **Used** when it's gone. The Need and supply screen mentions offcuts when that colour is next needed, so check here before cutting a fresh sheet.
